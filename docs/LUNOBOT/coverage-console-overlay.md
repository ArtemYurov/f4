# Test coverage — console image overlay key

Codecov показывает нулевое покрытие `cmd/f4/image_console_overlay.go`.
Добавлен тест `consoleFrameKey`: неизменный кадр сохраняет ключ, а изменение
изображения, положения, crop-параметров, числа частей или общей геометрии
создаёт новый ключ.

Проверка выполняется GitHub CI; локальные Go-сборки и тесты не запускаются по
инструкции Лунобота.
