# Кастомная задача покрытия `vtvibe/pack.go`

## Статус

Первый CI run 34320448447 выявил ошибку в граничном тесте бинарного обнаружения: `make([]byte, 8193)` заполняет первые 8193 байта NUL’ами. Исправлено на 8193 байта `x` с NUL после границы. Локальные сборка и тесты не запускались согласно инструкции Лунобота; повторная проверка выполняется в CI.
