## Решения и инварианты

- Нельзя восстанавливать логические строки эвристикой по ширине строки и CRLF: это может незаметно склеить настоящие строки или потерять данные.
- `conpty.dll` и `OpenConsole.exe` должны поставляться согласованной парой из одного проверенного пакета; подмена только одного файла недопустима.
- Для Windows amd64 и arm64 используется пакет
  `Microsoft.Windows.Console.ConPTY.1.25.260710002-preview.nupkg` из релиза
  `v1.25.1912.0`, SHA-256
  `05fe9b571ea4fb198f5012405cb39a132cf23eee50feaa496524c149b2502692`.
- В обычном запуске f4 ищет пару только рядом с собственным exe; нативные
  Windows-тесты устанавливают ту же пару в каталог пакета до запуска тестов.
- Поведение реального Windows и минимальная версия ОС должны быть подтверждены GitHub Windows CI; локальные сборки и тесты не запускаются.
- Документы `docs/CONPTY_LINE_WRAP_FINDINGS.md`, `docs/CONPTY_GATE_REQUIREMENTS.md` и `docs/CONPTY_NATIVE_TEST.md` описывают предпосылки и измерения, но сами по себе не доказывают интеграцию пары в f4.
