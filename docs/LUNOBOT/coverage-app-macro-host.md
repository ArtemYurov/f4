# Coverage: internal/app/macro_host.go

Задача: кастомное повышение покрытия по § 22 п. 3 LUNOBOT.md. На Codecov файл имел 0.00% покрытия при 114 строках.

Добавлены детерминированные тесты для nil- и обычного FrameManager, UI-вызовов macro host, состояния панелей, командной строки, размеров экрана, сообщений, инъекции событий, plugin-call и отключённого reload макросов.

После первого прохода тесты переведены на helper, который обслуживает UI TaskChan для синхронных вызовов onUI. Диагностика gofmt показала и исправила отсутствующий завершающий перевод строки в тестовом файле. Локальные Go-сборки и тесты не запускались по инструкции Лунобота; результат проверяется через GitHub Actions.

Ветка содержит временный diagnostic workflow для получения diff gofmt через CI; после диагностики workflow будет удалён до слияния.
